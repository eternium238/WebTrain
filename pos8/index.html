CSS 2.1

8 сентября 2009 года утверждена CSS2.1. Спецификация формировалась более 10 лет. Исправлены ошибки CSS2, изменения соответствия реальным браузерам, удалены устаревшие фрагменты, добавлены новые значения свойств.

CSS3 — самая значительная версия. Модульная структура открыла возможности для анимации, гибкой верстки, адаптивного дизайна. Эксперимент: сравнение разработки одной страницы на CSS2 и CSS3 показал впечатляющие результаты.

Позиционирование в CSS

Свойства position и float — основа управления расположением элементов. Отказ от табличной вёрстки даёт гибкость и чистый код. Рассмотрим ключевые значения position.

ЗначениеВид позиционированияОписание
staticНормальный поток (по умолчанию)Обычный блок, left/top не работают.
relativeОтносительноеСмещение относительно нормальной позиции, другие элементы не затронуты.
absoluteАбсолютноеПозиционирование относительно ближайшего позиционированного контейнера. Вырывается из потока.
fixedФиксированноеОтносительно окна браузера, не двигается при прокрутке.

Обтекание слева (по варианту): иллюстрация с использованием свойства float: left. Текст плавно обтекает изображение, это классический приём для гибкой вёрстки без таблиц. Вместе с CSS-позиционированием получаем мощную систему.

В CSS2 и CSS3 свойство float активно используется. Наш рекламный блок зафиксирован сверху, на страницах используются все виды позиционирования: fixed (кнопка в углу), relative (примеры), absolute (бейджи), static (по умолчанию).

Свойство position

  • Значение по умолчанию: static
  • Наследуемые значения: left, top (не наследуются, но влияют)
  • Применяется ко всем элементам
  • Совместимость: все современные браузеры

Благодаря позиционированию достигаются сложные макеты, создаются всплывающие слои, выпадающие меню. Используйте absolute и relative для точечного управления.

CSS-демонстрация: все типы позиционирования (static, relative, absolute, fixed) + обтекание слева + две колонки текста. Рекламный блок сверху. Меню с эффектами.
